# Планировщик задач (TODO-сервер)

Итоговый проект: REST API веб-сервер планировщика задач со связкой с веб-интерфейсом и базой данных SQLite.

## Задания со звездочкой
- Правила повторения w и m (недели и дни месяца)
- Поиск задач по ключевым словам и дате
- Аутентификация через JWT и переменная TODO_PASSWORD
- Dockerfile для сборки и запуска в контейнере

## Локальный запуск
go run main.go
Веб-интерфейс доступен по адресу: http://localhost:7540

## Запуск тестов
go test -v ./tests
